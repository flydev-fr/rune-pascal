# Changelog

## 0.1.0

- Replace vendor snapshots with pinned Rune and mORMot2 Git submodules.
- Keep reference-demo adapters outside upstream sources and preserve verified static inputs.

- Extract the reusable Rune C/Pascal integration as an independent development tree.
- Rust bridge, generated Delphi/FPC bindings, RuneUi and RuneVcl.
- Native controls, shader buttons, formatted document rendering and themed combobox.
- Five examples, Rust/mORMot regression suites and independent SDK packaging.

This SDK version is independent of the reader application version (0.3.0).
