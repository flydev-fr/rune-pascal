# Using Rune from Pascal

src/pascal/RunePas.pas is generated with ChetCLI from the C header; RuneUi.pas is an
optional facade; RuneVcl.pas hosts a GPU surface inside a VCL-owned HWND. None of
these units depend on the Markdown library model.

Start with examples/pascal/TodoPas.dpr for a standalone window, or RuneVclDemo.dpr
and RuneVclScene.pas for embedding. ShaderButtonsPas.dpr demonstrates eight Lab
button effects. Build with build.ps1 -Examples and keep the DLL beside the EXEs.

Build a tree transaction with BeginView, stable IDs, rows/columns and controls,
styles, then Commit. AbortView on errors. Handle events in Pascal and defer
rebuilding or freeing the control to the VCL message loop, outside Rust callbacks.

RuneUiTheme is shared by chrome and native document rendering. RUNE_UI_MODAL
creates a modal column directly below the root, one per tree; DEFAULT_BUTTON
designates the Enter action. RUNE_UI_COPY carries a borrowed UTF-8 copy request.
TRunePanel converts it to Windows Unicode text.

The VCL host requires Delphi. Generated bindings and compatible standalone
examples support FPC 3.2.3 or later; this is not a Lazarus port of the VCL app.

Bindings are generated by https://github.com/flydev-fr/chet-cli, based on Chet and
Neslib.Clang by Erik van Bilsen. Regenerate them using the repository script so
both the wrapper's and original engine's credits remain intact.

## Native combobox

Add a `RUNE_UI_COMBOBOX` leaf with 1..64 nonempty newline-separated option labels,
then call `rune_ui_set_choice(id, index)` with its zero-based controlled selection.
`RUNE_UI_CHOICE` delivers the node ID and chosen index. Accept the change in the
Pascal model and rebuild outside the callback. Invalid indexes leave the pending
node unchanged. The dropdown is layered outside clipped containers and anchored
to the trigger. Stable IDs preserve search/open state across host commits.

For localized search hints, `rune_ui_set_hint` accepts three newline-separated
strings for this node kind: accessible label, search placeholder, empty message.
A consuming application owns the selected value and its localized hints.
